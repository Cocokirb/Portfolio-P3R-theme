# Persona 3 Web Portfolio

A highly interactive, stylized web portfolio inspired by the sleek, dynamic user interface of Persona 3 Reload. This project was personalized for Fatar Gaza (Shiki), featuring smooth animations, gamepad support, and immersive audio feedback.

## Features

- **Immersive UI/UX:** Faithfully recreates the vibrant and dynamic menu styling of Persona 3.
- **Interactive Navigation:** Fully navigable using keyboard, mouse, and gamepads.
- **Audio Feedback:** Authentic hover, confirm, and cancel sound effects for a true game-like experience.

## Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router DOM
- **Styling:** Pure CSS (Custom Animations, Keyframes, Clip-paths)
- **Deployment:** Ready for Nginx / Cloud hosting with CI/CD

## Getting Started

First, make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Install Dependencies

Clone the repository and install the required NPM packages:
```bash
npm install
```

### 2. Run the Development Server

Start the local server with Vite:
```bash
npm run dev
```
Open `http://localhost:5173` with your browser to see the result.

### 3. Build for Production

To create an optimized production build:
```bash
npm run build
```
